The Screeps game client is not part of Krebs. To play, you need your own copy of the client from Steam. The game sprites

## 1. Projects Krebs derives from

Krebs follows the official Screeps server closely, so that bots written for the game run unchanged. Much of its game
logic is a port of the code below, and some of it is that code with changes. Over 200 Rust and JavaScript files start with
a line such as `mirror: reference/engine/src/game/creeps.js`, which names the upstream file they follow. `reference/` is the
author's local copy of these projects. It is not published.

| Project | Version used | Licence | What Krebs takes from it |
| --- | --- | --- | --- |
| [screeps/engine](https://github.com/screeps/engine) | 4.3.2, commit 8097782 | ISC | `crates/engine` is a Rust port of its processor. `crates/runtime/js/engine` is its game API, copied with changes. |
| [screeps/driver](https://github.com/screeps/driver) | 5.3.0, commit cf63d8a | ISC | `crates/runtime/js/driver` is copied with changes. `crates/pathfinder` is a Rust port of its native pathfinder, `native/src/pf.cc`, whose author line names Marcel Laverdet. `crates/engine/src/runner` follows its runner. |
| [screeps/common](https://github.com/screeps/common) | 2.16.1, commit 2fb779b | ISC | `crates/runtime/js/common`, `crates/runtime/js/cli/storage.js`, game constants. |
| [screeps/backend](https://github.com/screeps/backend) | 3.3.0 | ISC | `crates/backend` follows its API and sockets. `crates/runtime/js/cli` is its server console, copied with changes. |
| [screeps/storage](https://github.com/screeps/storage) | 5.1.3, commit 3d6c3d0 | ISC | `crates/engine/src/loki.rs` ports its database upgrade step. |
| [screeps/launcher](https://github.com/screeps/launcher) | 4.2.0 | ISC | Test data and one mod's behaviour follow its default world and example mods. |
| [screeps/renderer](https://github.com/screeps/renderer) | master, 2026-11-06 | ISC | All 68 sprites in `mods/bare/game-assets`, from its `metadata/images`. All 68 are unchanged copies. `mods/bare/render.js` draws them by the recipes in its `metadata`. |
| [lodash](https://lodash.com) | 3.10.1 | MIT | `crates/runtime/js/vendor/lodash.js`, unchanged. Bots use it as `_`. |
| [Node.js](https://nodejs.org) | 22 | MIT | `crates/runtime/js/cli/inspect.js` is a port of part of `lib/internal/util/inspect.js`. |
| [PathFinding.js](https://github.com/qiao/PathFinding.js), as @screeps/pathfinding | 0.4.17 | MIT | The `Node` constructor in `crates/runtime/js/driver/mapgrid.js`. The rest of that library is not included. |
| [xxscreeps](https://github.com/laverdet/xxscreeps) | commit d1e3bad | ISC | Design reference only, see section 4. |
| [rusty_v8](https://github.com/denoland/rusty_v8) | crate `v8` 152.2.0 | MIT | `vendor/v8`, the Rust bindings to V8. |
| [V8](https://v8.dev) | 15.2.124.1 | BSD-3-Clause | Runs the bots. Compiled into the Krebs program. |

Test fixtures under `crates/*/tests/fixtures` are recorded output of the projects above, mostly the official Screeps code run
on made-up worlds with made-up players. They are covered by the same notices.

## 9. V8 and what it compiles in

The Krebs program links V8 15.2.124.1 as a static library. Krebs's release builds compile it from source, with the small
changes in `tools/v8-ptrcomp.patch`. V8's own source is not in this repository: `tools/v8-ptrcomp.ps1` fetches it from the
published `v8` crate.

The list below is what goes into that library on Windows x64. It comes from the build's own file list, `obj/rusty_v8.ninja`,
and from the headers V8's source includes.
